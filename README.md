# Horror Roguelike

Downloads und automatische Updates für **Horror Roguelike** – ein düsteres Action-Roguelike, allein oder zu zweit.

## Installieren (nur einmal nötig)

1. Rechts unter **Releases** die neueste Version öffnen und die Datei `HorrorRoguelike-….zip` herunterladen.
2. Die ZIP-Datei in einen eigenen Ordner entpacken, z. B. `Dokumente\Spiele\Horror Roguelike`
   (nicht unter „Programme“ – dort kann sich das Spiel nicht selbst aktualisieren).
3. `HorrorRoguelike.exe` starten. Beim ersten Start warnt Windows eventuell
   („Der Computer wurde durch Windows geschützt“): **Weitere Informationen → Trotzdem ausführen**.

## Updates

Das Spiel prüft bei jedem Start, ob es eine neue Version gibt. Mit **Jetzt aktualisieren** wird sie
heruntergeladen und installiert, danach startet das Spiel neu. Spielstände bleiben erhalten.

## Zusammen spielen

Im Hauptmenü **Spiel erstellen** (Join-Code) oder **Im LAN hosten** (IP-Adresse); der Freund tritt mit dem
Code bzw. der IP bei. Beide brauchen dieselbe Version – ist eine veraltet, sagt das Spiel Bescheid.
